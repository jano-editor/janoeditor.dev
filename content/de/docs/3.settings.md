## Der Settings-Dialog

`F9` drücken. Pfeile bewegen, `Links` / `Rechts` oder `Enter` ändern einen Wert, `Esc` geht zurück. Änderungen gelten sofort und werden gespeichert.

| Einstellung            | Standard | Was sie tut                                                                                                                   |
| ---------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Tab Size               | `2`      | Breite eines Tabs und einer Einrückstufe: 2, 4 oder 8                                                                         |
| Insert Spaces          | an       | `Tab` fügt Leerzeichen ein. Aus: ein echtes Tab-Zeichen                                                                       |
| Line Numbers           | an       | Die Zeilennummern links                                                                                                       |
| Auto Complete          | an       | Vorschläge erscheinen beim Tippen von selbst. `Ctrl+Space` geht immer                                                         |
| Startup Animation      | an       | Die kurze „jano“-Animation in der Titelleiste                                                                                 |
| Plugin Recommendations | an       | Der Willkommens-Dialog beim Start, der Plugins vorschlägt. Hast du entschieden, kommt er nur für neue Plugins im Store wieder |
| Reset to defaults      |          | Zurück auf die Werte oben                                                                                                     |

Die Settings liegen in `config.json` im Konfigurationsordner von jano: `~/.config/jano/` unter Linux, `~/Library/Application Support/jano/` unter macOS, `%APPDATA%\jano\` unter Windows.

## .editorconfig

Viele Projekte haben eine [`.editorconfig`](https://editorconfig.org), die festlegt, wie Dateien eingerückt werden. jano liest sie für jede Datei, die es öffnet, unter neuem Namen speichert oder wiederherstellt. Gesucht wird im Ordner der Datei und in jedem übergeordneten Ordner, bis eine Datei `root = true` sagt.

```ini [.editorconfig]
root = true

[*]
indent_style = space
indent_size = 2
end_of_line = lf
trim_trailing_whitespace = true
insert_final_newline = true

[Makefile]
indent_style = tab
tab_width = 8
```

jano versteht diese Eigenschaften:

| Eigenschaft                 | Wirkung in jano                                                           |
| --------------------------- | ------------------------------------------------------------------------- |
| `indent_style`              | `space` oder `tab`, wie _Insert Spaces_                                   |
| `indent_size` / `tab_width` | Die Tab-Breite. Bei Tabs zählt `tab_width`, bei Leerzeichen `indent_size` |
| `end_of_line`               | `lf` oder `crlf`, für neue Dateien                                        |
| `charset`                   | `utf-8` oder `utf-8-bom`, für neue Dateien                                |
| `trim_trailing_whitespace`  | Entfernt beim Speichern Leerzeichen am Zeilenende                         |
| `insert_final_newline`      | Sorgt beim Speichern für einen Zeilenumbruch am Dateiende                 |

Bestehende Dateien behalten ihre Zeilenenden und ihr BOM, jano ändert eine Datei nicht, nur weil du sie geöffnet hast. Die beiden Speicher-Regeln laufen nach dem `onSave` des Plugins und sind zusammen ein Schritt, `Ctrl+Z` nimmt sie also zurück.

### Wer gewinnt

Die Werte des Projekts gewinnen über deine, aber nur für Dateien dieses Projekts. Deine eigenen Settings werden nie überschrieben. `F9` zeigt, woher ein Wert kommt:

```text
Insert Spaces  on   · project: off (.editorconfig)
```

Hier magst du Leerzeichen, das Projekt will Tabs, und jano nimmt Tabs. Öffnest du eine Datei woanders, hast du wieder deine Leerzeichen.
