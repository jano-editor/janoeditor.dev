title: Shortcuts
description: Die Tasten, die du aus jedem anderen Editor kennst. F1 zeigt sie in jano jederzeit an.

## Dateien

| Tasten   | Aktion                                                      |
| -------- | ----------------------------------------------------------- |
| `Ctrl+S` | Speichern. Eine neue Datei fragt vorher nach dem Namen      |
| `Ctrl+Q` | Beenden. Fragt nach, wenn es ungespeicherte Änderungen gibt |
| `Ctrl+R` | Ungespeicherte Dateien nach einem Absturz wiederherstellen  |

## Bearbeiten

| Tasten                         | Aktion                                                                    |
| ------------------------------ | ------------------------------------------------------------------------- |
| `Ctrl+Z` / `Ctrl+Y`            | Rückgängig / Wiederholen, die Cursor kommen mit zurück                    |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Ausschneiden / Kopieren / Einfügen                                        |
| `Ctrl+A`                       | Alles markieren                                                           |
| `Ctrl+Backspace` / `Ctrl+Entf` | Wort vor / nach dem Cursor löschen                                        |
| `Alt+Hoch` / `Alt+Runter`      | Zeile nach oben / unten verschieben                                       |
| `Tab`                          | Einrücken, mit Leerzeichen oder Tab je nach [Settings](/de/docs/settings) |

## Bewegen und markieren

| Tasten                                               | Aktion                                                        |
| ---------------------------------------------------- | ------------------------------------------------------------- |
| Pfeile, `Pos1` / `Ende`, `Bild hoch` / `Bild runter` | Cursor bewegen                                                |
| `Ctrl+Links` / `Ctrl+Rechts`                         | Wortweise springen                                            |
| `Shift` + eine der Tasten oben                       | Markieren                                                     |
| `Ctrl+F`                                             | Suchen mit Live-Ergebnissen. `Tab` wechselt ins Ersetzen-Feld |
| `Ctrl+G`                                             | Zu einer Zeilennummer springen, oder an Anfang oder Ende      |

## Multi-Cursor

| Tasten                                  | Aktion                                                                                   |
| --------------------------------------- | ---------------------------------------------------------------------------------------- |
| `Ctrl+D`                                | Wort markieren, dann jeden nächsten Treffer. Jeder Treffer bekommt einen Cursor          |
| `Ctrl+Shift+Hoch` / `Ctrl+Shift+Runter` | Cursor darüber / darunter hinzufügen. Unter Windows: `Ctrl+Alt+Hoch` / `Ctrl+Alt+Runter` |
| `Esc`                                   | Zurück zu einem Cursor                                                                   |

Tippen, Löschen, Kopieren und Einfügen und Autocomplete wirken an jedem Cursor. Mit drei Cursorn kopiert und mit drei Cursorn eingefügt, bekommt jeder seinen eigenen Teil.

## Autocomplete

| Tasten                     | Aktion                         |
| -------------------------- | ------------------------------ |
| `Ctrl+Space` oder `Ctrl+N` | Vorschläge zeigen              |
| `Tab` / `Enter`            | Gewählten Vorschlag übernehmen |
| `Esc`                      | Liste schließen                |

Die Vorschläge kommen vom Sprach-Plugin und aus den Wörtern der Datei. Beim Tippen erscheinen sie auch von selbst, das lässt sich in den Settings abschalten.

## Funktionstasten

| Taste | Aktion                                                           |
| ----- | ---------------------------------------------------------------- |
| `F1`  | Hilfe mit allen Shortcuts                                        |
| `F2`  | Verlauf: jede Änderung der Sitzung, Sprung an jeden Punkt zurück |
| `F3`  | Datei formatieren (braucht ein Plugin, das formatieren kann)     |
| `F4`  | Diagnose: Fehler und Warnungen, die das Plugin gefunden hat      |
| `F9`  | [Settings](/de/docs/settings)                                    |

## Maus

Klick setzt den Cursor, Doppelklick markiert ein Wort, Dreifachklick eine Zeile. Ziehen markiert, an den Rändern scrollt die Ansicht mit. Das Mausrad scrollt.

## Auf dem Mac

jano nutzt auch unter macOS `Ctrl`, nicht `Cmd`: Die `Cmd`-Taste behält das Terminal für sich. `Cmd+V` fügt trotzdem ein, weil das Terminal den Text an jano weitergibt.

Für `Alt+Hoch` / `Alt+Runter` muss die `Option`-Taste bei jano ankommen. In Terminal.app _Wahltaste als Meta-Taste verwenden_ einschalten (Einstellungen › Profile › Tastatur), in iTerm2 _Left Option key_ auf _Esc+_ stellen (Settings › Profiles › Keys).
