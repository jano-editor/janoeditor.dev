## Dateien öffnen

| Befehl                 | Was er tut                                                               |
| ---------------------- | ------------------------------------------------------------------------ |
| `jano <datei>`         | Eine Datei öffnen. Gibt es sie nicht, entsteht sie beim ersten Speichern |
| `jano`                 | Mit einer leeren Datei starten, der Name wird beim Speichern abgefragt   |
| `jano --debug <datei>` | Genauso, mit [Debug-Logs](/de/docs/troubleshooting#debug-logs)           |
| `jano --version`, `-v` | Version ausgeben                                                         |
| `jano --help`, `-h`    | Hilfe ausgeben                                                           |

## Plugins

| Befehl                                 | Was er tut                                                     |
| -------------------------------------- | -------------------------------------------------------------- |
| `jano plugin search`                   | Alle Plugins im Store auflisten                                |
| `jano plugin search <text>`            | Nach Name, Beschreibung oder Dateiendung suchen                |
| `jano plugin install <name>`           | Die neueste Version installieren                               |
| `jano plugin install <name>@<version>` | Eine bestimmte Version installieren                            |
| `jano plugin list`                     | Installierte Plugins zeigen, und warum ein kaputtes nicht lädt |
| `jano plugin remove <name>`            | Ein Plugin entfernen                                           |

Plugins liegen in `~/.local/share/jano/plugins/` unter Linux, `~/Library/Application Support/jano/plugins/` unter macOS und `%LOCALAPPDATA%\jano\plugins\` unter Windows. jano findet sie dort auch, wenn du es mit `sudo` startest.

## Aktualisieren

```bash
jano update
```

jano erkennt, wie es installiert wurde, und aktualisiert sich auf demselben Weg: Homebrew über `brew`, npm über `npm`, das Install-Skript, indem es die neue Datei lädt, gegen die veröffentlichte Prüfsumme prüft und an Ort und Stelle austauscht. Unter Windows vorerst den Install-Befehl noch einmal ausführen.

## Umgebungsvariablen

| Variable       | Wirkung                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `JANO_HOME`    | Konfiguration, Plugins, Cache und Backups in diesen einen Ordner legen. Praktisch für ein portables Setup oder zum Testen |
| `JANO_DEBUG=1` | Dasselbe wie `--debug`                                                                                                    |
