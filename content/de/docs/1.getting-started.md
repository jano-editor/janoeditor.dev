## Installieren

Unter Linux und macOS:

```bash
curl -fsSL https://janoeditor.dev/install.sh | bash
```

Mit Homebrew:

```bash
brew tap jano-editor/jano && brew install jano
```

Unter Windows, in der PowerShell:

```powershell
irm https://janoeditor.dev/install.ps1 | iex
```

jano ist eine einzelne Datei. Es braucht kein Node.js, keine Laufzeitumgebung und keine Konfigurationsdatei. Das Install-Skript prüft den Download gegen die veröffentlichten Prüfsummen, bevor es etwas auf deinem System ablegt.

## Eine Datei öffnen

```bash
jano notizen.md
```

Ohne Dateinamen startet jano mit einem leeren Puffer und fragt beim Speichern nach dem Namen. Tippen, dann `Ctrl+S` zum Speichern und `Ctrl+Q` zum Beenden. Gibt es ungespeicherte Änderungen, fragt jano vorher nach.

`F1` zeigt jederzeit alle Shortcuts.

## Sprachen dazunehmen

jano selbst kennt keine Sprache. Highlighting, Formatierung und Autocomplete kommen aus Plugins. Beim ersten Start schlägt ein Willkommens-Dialog die gängigen vor. `Enter` drücken, und sie sind sofort installiert und aktiv, ohne Neustart.

Plugins lassen sich auch über die Kommandozeile installieren:

```bash
jano plugin install python
```

Alle Plugins stehen im [Plugin Store](/de/plugins).

## Aktuell bleiben

```bash
jano update
```

jano weiß, wie es installiert wurde (Install-Skript, Homebrew oder npm), und aktualisiert sich auf demselben Weg. Ist eine neue Version da, zeigt ein Banner beim Start Bescheid.
