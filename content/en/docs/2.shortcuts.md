## Files

| Keys     | Action                                          |
| -------- | ----------------------------------------------- |
| `Ctrl+S` | Save. A new file asks for a name first          |
| `Ctrl+Q` | Quit. Asks first when there are unsaved changes |
| `Ctrl+R` | Recover unsaved files after a crash             |

## Editing

| Keys                             | Action                                                                    |
| -------------------------------- | ------------------------------------------------------------------------- |
| `Ctrl+Z` / `Ctrl+Y`              | Undo / redo, the cursors come back too                                    |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V`   | Cut / copy / paste                                                        |
| `Ctrl+A`                         | Select all                                                                |
| `Ctrl+Backspace` / `Ctrl+Delete` | Delete the word before / after the cursor                                 |
| `Alt+Up` / `Alt+Down`            | Move the line up / down                                                   |
| `Tab`                            | Indent, with spaces or a tab depending on your [settings](/docs/settings) |

## Moving and selecting

| Keys                                    | Action                                                    |
| --------------------------------------- | --------------------------------------------------------- |
| Arrows, `Home` / `End`, `PgUp` / `PgDn` | Move the cursor                                           |
| `Ctrl+Left` / `Ctrl+Right`              | Jump word by word                                         |
| `Shift` + any of the above              | Select                                                    |
| `Ctrl+F`                                | Search, live results. `Tab` switches to the replace field |
| `Ctrl+G`                                | Go to a line number, or to the start or end               |

## Multi-cursor

| Keys                                | Action                                                                  |
| ----------------------------------- | ----------------------------------------------------------------------- |
| `Ctrl+D`                            | Select the word, then each next match. Every match gets a cursor        |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | Add a cursor above / below. On Windows: `Ctrl+Alt+Up` / `Ctrl+Alt+Down` |
| `Esc`                               | Back to one cursor                                                      |

Typing, deleting, copy and paste and autocomplete work at every cursor. Copy with three cursors and paste with three cursors, and each one gets its own part.

## Autocomplete

| Keys                     | Action                       |
| ------------------------ | ---------------------------- |
| `Ctrl+Space` or `Ctrl+N` | Show suggestions             |
| `Tab` / `Enter`          | Take the selected suggestion |
| `Esc`                    | Close the list               |

Suggestions come from the language plugin and from the words in the file. They also show up on their own while you type, you can turn that off in the settings.

## Function keys

| Key  | Action                                                       |
| ---- | ------------------------------------------------------------ |
| `F1` | Help with every shortcut                                     |
| `F2` | History: every change of the session, jump back to any point |
| `F3` | Format the file (needs a plugin that can format)             |
| `F4` | Diagnostics: errors and warnings the plugin found            |
| `F9` | [Settings](/docs/settings)                                   |

## Mouse

Click to place the cursor, double-click selects a word, triple-click a line. Drag to select, the view scrolls along at the edges. The scroll wheel scrolls.

## On a Mac

jano uses `Ctrl` on macOS too, not `Cmd`: the terminal keeps the `Cmd` key for itself. `Cmd+V` still pastes, because the terminal hands the text to jano.

For `Alt+Up` / `Alt+Down`, the `Option` key has to reach jano. In Terminal.app turn on _Use Option as Meta key_ (Settings › Profiles › Keyboard), in iTerm2 set _Left Option key_ to _Esc+_ (Settings › Profiles › Keys).
