## Opening files

| Command                | What it does                                                     |
| ---------------------- | ---------------------------------------------------------------- |
| `jano <file>`          | Open a file. It is created on the first save if it doesn't exist |
| `jano`                 | Start with an empty file, the name is asked on save              |
| `jano --debug <file>`  | Same, with [debug logs](/docs/troubleshooting#debug-logs)        |
| `jano --version`, `-v` | Print the version                                                |
| `jano --help`, `-h`    | Print the help                                                   |

## Plugins

| Command                                | What it does                                              |
| -------------------------------------- | --------------------------------------------------------- |
| `jano plugin search`                   | List all plugins in the store                             |
| `jano plugin search <text>`            | Search by name, description or file extension             |
| `jano plugin install <name>`           | Install the newest version                                |
| `jano plugin install <name>@<version>` | Install a specific version                                |
| `jano plugin list`                     | Show installed plugins, and why a broken one doesn't load |
| `jano plugin remove <name>`            | Remove a plugin                                           |

Plugins are stored in `~/.local/share/jano/plugins/` on Linux, `~/Library/Application Support/jano/plugins/` on macOS and `%LOCALAPPDATA%\jano\plugins\` on Windows. jano finds them there even when you run it with `sudo`.

## Updating

```bash
jano update
```

jano detects how it was installed and updates the same way: Homebrew through `brew`, npm through `npm`, the install script by downloading the new binary, checking it against the published checksum and swapping it in place. On Windows, run the install command again for now.

## Environment variables

| Variable       | Effect                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| `JANO_HOME`    | Put config, plugins, cache and backups into this one folder. Handy for a portable setup or for testing |
| `JANO_DEBUG=1` | The same as `--debug`                                                                                  |
