## The settings dialog

Press `F9`. Arrows move, `Left` / `Right` or `Enter` change a value, `Esc` goes back. Changes apply right away and are saved.

| Setting                | Default | What it does                                                                                                         |
| ---------------------- | ------- | -------------------------------------------------------------------------------------------------------------------- |
| Tab Size               | `2`     | Width of a tab and of one indent step: 2, 4 or 8                                                                     |
| Insert Spaces          | on      | `Tab` inserts spaces. Off: a real tab character                                                                      |
| Line Numbers           | on      | The line numbers on the left                                                                                         |
| Auto Complete          | on      | Suggestions pop up on their own while typing. `Ctrl+Space` works either way                                          |
| Startup Animation      | on      | The short "jano" animation in the title bar                                                                          |
| Plugin Recommendations | on      | The welcome dialog on start that suggests plugins. Once you decided, it only comes back for plugins new in the store |
| Reset to defaults      |         | Back to the values above                                                                                             |

The settings live in `config.json` in jano's config folder: `~/.config/jano/` on Linux, `~/Library/Application Support/jano/` on macOS, `%APPDATA%\jano\` on Windows.

## .editorconfig

Many projects ship an [`.editorconfig`](https://editorconfig.org) file that says how files are indented. jano reads it for every file it opens, saves under a new name or restores. It looks in the file's folder and every parent folder, until a file says `root = true`.

```ini [.editorconfig]
root = true

[*]
indent_style = space
indent_size = 2
end_of_line = lf
trim_trailing_whitespace = true
insert_final_newline = true

[Makefile]
indent_style = tab
tab_width = 8
```

jano understands these properties:

| Property                    | Effect in jano                                                         |
| --------------------------- | ---------------------------------------------------------------------- |
| `indent_style`              | `space` or `tab`, the same as _Insert Spaces_                          |
| `indent_size` / `tab_width` | The tab size. With tabs, `tab_width` counts, with spaces `indent_size` |
| `end_of_line`               | `lf` or `crlf`, for new files                                          |
| `charset`                   | `utf-8` or `utf-8-bom`, for new files                                  |
| `trim_trailing_whitespace`  | Removes spaces at the end of lines on save                             |
| `insert_final_newline`      | Makes sure the file ends with a newline on save                        |

Existing files keep their line endings and BOM, jano doesn't change a file just because you opened it. The two save rules run after the plugin's `onSave` and are one undo step together, so `Ctrl+Z` takes them back.

### Who wins

The project's values win over yours, but only for files of that project. Your own settings are never overwritten. `F9` shows where a value comes from:

```text
Insert Spaces  on   · project: off (.editorconfig)
```

Here you prefer spaces, the project wants tabs, and jano uses tabs. Open a file somewhere else, and you get your spaces again.
